# It's All About the Money Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **It's All About the Money** (1.7.10) by Freakin_Sweet.

- Original: https://www.planetminecraft.com/mod/itsallaboutthemoney-mc1710/
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.36.1+

This port contains **no original assets**. Put your own copy of the original jar (`Its_All_About_Money_Mod_1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures from it at runtime.
